# HAS Analytics — Portal empresarial

Portal institucional e sistema de atendimento construído com Next.js, Vercel e Supabase.

## Configuração

1. Crie um projeto no Supabase.
2. Execute `supabase/schema.sql` no SQL Editor.
3. Copie `.env.example` para `.env.local` e informe URL e chave anônima.
4. Crie o usuário administrador no Supabase Authentication e execute o comando indicado no final do schema.
5. Importe o repositório na Vercel e cadastre as mesmas variáveis.

## Áreas

- site público e portfólio horizontal;
- comentários com aprovação administrativa;
- login de clientes;
- documentos, contratos, recibos e relatórios;
- painel administrativo preparado para expansão.
